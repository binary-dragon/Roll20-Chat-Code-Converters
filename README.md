# Roll20- Code Converters - Master Read Me
A set of  light Roll20 Scripts for in chat binary/hex/morse code to text conversion. Styled for Cyberpunk Red and Modern TTRPGs

# -- Binary Converter

// `!xtb` [Text] - Converts Text to Binary, posts result in public chat.  
// `!btx` [Binary] - Converts Binary to text, posts result in public chat.  
// `!xtbw` [Text] - Converts Text to Binary, whispers result to user.  
// `!btxw` [Binary] - Converts Binary to text, whispers result to user.

## -- Keeping it Tidy -- App Menu Macro.  
Install individually or as a suite. Use the Macro script to keep them together in a neat little pull down menu. Make that a token action and it will always be availible to your players.   
Feel free to download and use. You will need Roll20 Api (Roll20 Pro etc) access to run these scripts.
